# Project Nox · Extensões de Anime

Repositório oficial de distribuição e catálogo compilado de extensões de anime e streaming para **Aniyomi**, **Anikku** e forks compatíveis.

---

## 🎯 Para quem é este repositório?

Este repositório é voltado para **usuários e espectadores** que desejam instalar e manter atualizadas as extensões de reprodução de anime, filmes e séries diretamente em seus aplicativos móveis.

Se você procura o **código-fonte em Kotlin**, extractors de vídeo ou deseja contribuir tecnicamente com correções, acesse o repositório irmão:  
➡️ [**Project Nox · Código-fonte das Extensões de Anime**](https://github.com/Awerkori/anime-fonte-extensoes)

---

## 📲 Como Adicionar ao Aniyomi / Anikku

### Método 1: Adicionar Automaticamente (Recomendado)
Toque no link abaixo a partir do seu celular para abrir o instalador do aplicativo:

👉 [**Adicionar Repositório ao Aplicativo**](aniyomi://add-repo?url=https%3A%2F%2Fraw.githubusercontent.com%2FAwerkori%2Fanime-extensoes%2Frepo%2Findex.min.json)

---

### Método 2: Adicionar Manualmente

1. No **Aniyomi** ou **Anikku**, abra **Configurações** → **Navegar** → **Repositórios de extensões de anime**.
2. Toque no botão **Adicionar** (`+`).
3. Cole a URL do catálogo:

```
https://raw.githubusercontent.com/Awerkori/anime-extensoes/repo/index.min.json
```

## ⚖️ Isenção de Responsabilidade

O **Project Nox** desenvolve e disponibiliza ferramentas de código aberto para interoperabilidade e automação. Não hospedamos, modificamos ou controlamos o streaming nem arquivos de vídeo de terceiros acessados através das extensões, nem possuímos afiliação oficial com os desenvolvedores dos aplicativos Aniyomi ou Anikku.
